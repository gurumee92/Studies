## 📖 카테고리별 상세 설명

### 🤖 AI (Artificial Intelligence)
인공지능 관련 기술과 도구를 학습하는 공간입니다.
- **Langchain/**: Langchain 프레임워크를 활용한 AI 애플리케이션 개발 학습. LLM 통합, 체인 구축 등.
- **N8N/**: N8N 워크플로우 자동화 도구를 사용한 노코드/로우코드 AI 워크플로우 구축.
- **Python/**: Python 기초

### 💻 CS (Computer Science)
컴퓨터 과학의 기초 개념을 다루는 섹션입니다.
- **Algorithm/**: 다양한 알고리즘의 원리, 구현, 분석. 시간 복잡도, 최적화 기법 등.
- **Database/**: 데이터베이스 설계, SQL, NoSQL, 정규화, 트랜잭션 등.
- **Datastructure/**: 자료구조의 종류, 구현, 활용. 배열, 리스트, 트리, 그래프 등.
- **Network/**: 네트워크 기초, TCP/IP, HTTP, 보안 등.
- **ProgrammingBasic/**: 프로그래밍 언어의 기초를 학습.
  - **C/**: C 언어의 기본 문법, 메모리 관리, 포인터 등.
  - **C++/**: C++의 객체 지향 프로그래밍, STL, 템플릿 등.
  - **Rust/**: Rust의 안전한 메모리 관리, 소유권 시스템, 동시성 등.

### 🎮 Game
게임 개발 관련 기술을 탐구하는 곳입니다.
- **C#/**: C# 기초
- **Unity/**: Unity 엔진을 사용한 게임 개발.
  - **MasteringUnity/**: Unity의 고급 기능, 스크립팅, 에셋 관리 등 마스터링 과정.

### 🔧 SRE (Site Reliability Engineering)
시스템의 안정성과 신뢰성을 높이는 엔지니어링을 학습합니다. 모니터링, 자동화, 장애 대응, 클라우드 인프라 관리 등을 다룹니다.
- **CICD/**: 지속적 통합/배포(CI/CD) 파이프라인 구축 및 관리.
  - **Argocd/**: ArgoCD를 활용한 GitOps 기반 배포.
  - **GithubAction/**: GitHub Actions를 사용한 자동화 워크플로우.
  - **Tekton/**: Kubernetes 네이티브 CI/CD 도구 학습.
- **Container/**: 컨테이너화 기술, Docker, Kubernetes 등.
- **Golang/**: Go 언어를 활용한 시스템 프로그래밍, 마이크로서비스 구축, 동시성 처리, 네트워킹 등.
  - **TuckerGolang/**: Tucker의 Go 언어 강의를 기반으로 한 학습 자료. 기초부터 고급 주제까지.
- **IaC/**: Infrastructure as Code, Terraform, Ansible 등을 사용한 인프라 자동화.
- **Observerbility/**: 시스템 모니터링, 로깅, 트레이싱, Prometheus, Grafana 등.

## 🚀 사용 방법

1. **학습 자료 저장**: 각 폴더에 주제별로 노트(.md), 코드 파일(.py, .c 등), 예제 프로젝트를 저장하세요.
2. **체계적 정리**: 폴더 구조를 유지하며, 파일명을 명확하게 지어주세요 (예: `algorithm_sorting.md`).
3. **진행 상황 추적**: 학습 완료 시 체크리스트나 요약을 추가하여 진행도를 기록하세요.
4. **참고 및 공유**: 필요 시 다른 사람과 공유하거나, 나중에 복습할 때 활용하세요.
